PERSONAL CRM - SIMPLE INSTALLATION

What the user needs:
1. Windows 10 or Windows 11
2. Docker Desktop
3. This installer folder

Installation:
1. Install and start Docker Desktop.
2. Double-click INSTALL-CRM.bat.
3. Wait until the window says installation completed successfully.
4. Open http://127.0.0.1:5173/ in a browser.

Daily use:
- Double-click START-CRM.bat before using the CRM.
- Double-click STOP-CRM.bat when finished.
- Double-click STATUS-CRM.bat to check whether it is running.
- Double-click RESTART-CRM.bat if the CRM needs restarting.

Important:
- Do not delete the Docker volume or CRM data will be lost.
- Keep the .env file private.
- Read USER_INSTALLATION.md for backups, updates, and troubleshooting.

No Python, Node.js, npm, PostgreSQL, Git, or developer tools are required.
